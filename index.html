The gap

Building small tools got easy. Shipping them did not.

Agents can write a bespoke internal tool in seconds. Deploying, securing, and sharing it is still the hard part. Perch takes those three on, so the agent does not have to.

01

Runs arbitrary code, safely

Every tool executes in a locked-down sandbox with no filesystem, network, or host access. Its only capability is its own isolated storage, handed in by the platform. It survived an adversarial review that found a real escape, now fixed and regression-tested.

02

Auth and permissions, built in

Tools inherit your org identity. The platform authorizes every request before a line of tool code runs. Share by person, group, org, or public. Works behind your SSO with one env var.

03

Shared like a doc, owned like a file

Send a link the way you send a Google Doc. And eject the exact source to a zip whenever you want. No lock-in, ever.

Honest by design

It runs untrusted code, and says so plainly.

The sandbox is defense in depth: a vm with a deny-all import linker and no host-realm references, inside a process under Node's permission model, reads scoped away from the control-plane data. It shipped with a security review and a written threat model.

read first

Node's vm is not a hostile-multi-tenant guarantee on its own, so run Perch in one trust domain: your team, for its own members. That is also the target use case. The sandbox interface is built to swap in V8 isolates or Cloudflare Workers-for-Platforms for a public instance. This is stated in SECURITY.md so the boundary is never overclaimed.

Self-host in minutes

One container, your data, your identity.

Runs on any real container or VM host (Cloud Run, Fly, Render, a VM). Put it behind Cloudflare Access, Google IAP, or oauth2-proxy and it inherits your SSO with one env var. Watch /v1/stats for the signals that matter: repeat deploys and real shares.

self-host
$ docker build -t perch .
$ docker run -p 8787:8787 \
    -e PERCH_BASE_URL=https://tools.acme.com \
    -e PERCH_TRUSTED_PROXY_HEADER=x-forwarded-email \
    -v perch-data:/app/.perch-data \
    perch

# or just, locally:
$ npm install && npm run demo
